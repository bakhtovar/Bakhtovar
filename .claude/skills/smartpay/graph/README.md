# Граф знаний SmartPay

Отдельный граф по документации SmartPay: 171 узел, 359 связей, 9 сообществ.
Построен `/graphify` 8 сентября 2026 из 14 PDF документации (тексты в
`source-pdf-text/`) и пяти файлов самого скилла.

- `graph.html` — интерактивный граф, открывается в браузере без сервера
- `GRAPH_REPORT.md` — god nodes, неожиданные связи, гиперрёбра, сообщества
- `graph.json` — данные графа
- `source-pdf-text/` — распознанный текст исходных PDF, из которого строился граф

Это не граф репозитория. Граф кода Blast живёт отдельно в `graphify-out/` в
корне проекта, и они не смешаны намеренно: у документации внешнего платёжного
шлюза свой словарь, и в общем графе он бы утонул среди 4572 узлов кода.

Узлы помнят, из какого файла пришёл каждый факт, поэтому по графу видно, что
взято из официальной документации, а что достроено под Blast.

Самые связанные узлы: `POST /merchant/invoices` (32 связи),
`GET /merchant/banks` (18), webhook-уведомление (16).

Три гиперребра описывают три сквозных сценария: подтверждение оплаты через
webhook, диплинк-флоу от списка банков до приложения банка, и splitting
accounts от субагента до сверки переводов.
