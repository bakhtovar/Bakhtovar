Ошибки и статусы
SmartPay использует комбинацию HTTP-кодов и бизнес-кодов в теле ответа.
Важно
HTTP статус почти всегда 200. Бизнес-результат определяется полем
"result" в теле ответа.
HTTP Status Codes
CODE TITLE DESCRIPTION
200 OK Запрос выполнен. Бизнес-результат
определяется полем "result" в теле ответа.
400 Bad Request Неверные параметры запроса (только для
method=card в /payment/session).
401 Unauthorized Заголовок x-app-token отсутствует или токен
невалиден.
403 Forbidden Внутренняя ошибка проверки
аутентификации.
404 Not Found Запрашиваемый ресурс не найден (заказ,
сессия и т.д.).
409 Conflict Исключение из базы данных (например,
минимальная сумма инвойса).
500 Server Error Внутренняя ошибка сервера. Крайне редко.
Формат HTTP-ошибок
HTTP-ошибки (401, 403, 404, 409, 500) возвращают ответ в формате:
{ "detail": "Описание ошибки" }
Или массив строк:
{ "detail": ["Минимальная сумма инвойса должна быть 2 сомони"] }
Формат бизнес-ошибок (HTTP 200)
Бизнес-ошибки приходят внутри HTTP 200 с полем result отличным от 200 (или <
0):
{
  "result": 400,
  "message": "Error: Required data not found",
  "invoice_uuid": null,


  "smartpay_id": null,
  "payment_link": null
}
