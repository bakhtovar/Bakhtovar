API-ключи

Управление ключами доступно в личном кабинете: Танзимот (Settings) → API Keys.

1. Нажмите кнопку «Generate API Key» (справа над таблицей).
2. В модальном окне выберите окружение:
Production — для рабочей среды (ключ будет показан только один раз!)
Test — для тестирования
3. Введите описание (для чего этот ключ).


4. Нажмите «Generate API Key».
5. Скопируйте ключ и сохраните его в надёжном месте.
Внимание!
Production-ключ отображается только в момент создания. После закрытия окна его невозможно будет увидеть
снова. Обязательно сохраните его сразу.
