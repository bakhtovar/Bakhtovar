# Личный кабинет SmartPay

`https://dashboard.smartpay.tj`. Логин и пароль выдаёт аккаунт-менеджер
SmartPay, самостоятельной регистрации нет. Интерфейс трёхъязычный, разделы в
меню подписаны на таджикском.

## Разделы

| Меню | Таджикское название | Что делает |
|---|---|---|
| Dashboard | Панели идоракунӣ | Сводка за последние 30 дней |
| Инвойсы | Ҳисобномаҳо | Список инвойсов, создание, статусы |
| Отчёты | Ҳисоботҳо | Сводные таблицы за период, выгрузка в Excel |
| Переводы | Гузоришҳо | Консолидированные банковские переводы на расчётный счёт |
| Настройки | Танзимот | API Keys, Webhooks, Субагенты, Доступы |

## Роли и видимость

| Роль | Доступ |
|---|---|
| Супервайзер | Всё: дашборд, инвойсы, отчёты, переводы, настройки, доступы |
| Бухгалтер | Просмотр без управления: дашборд, инвойсы, отчёты, переводы |
| Оператор | Только свои инвойсы: дашборд, инвойсы (свои), отчёты (свои) |

Вкладку «Доступы» видит только супервайзер. Раздел «Переводы» операторам не
показывается. Самого супервайзера нельзя отредактировать или заблокировать —
кнопок действий у него нет. Заблокированные пользователи остаются в списке со
статусом «Неактивен».

## API-ключи

Настройки → API Keys.

| Тип ключа | Видимость |
|---|---|
| Test | Виден и копируется в любой момент, иконка «глаз» |
| Production | Всегда замаскирован. **Показывается только в момент создания** |

Создание: «Generate API Key» → выбрать окружение (Production / Test) → описание
→ «Generate API Key» → сразу скопировать и сохранить.

Production-ключ после закрытия окна восстановить невозможно. Потерян — только
выпускать новый.

## Инвойсы

Таблица: номер (формат `XXX-XXXXXXXXX`), дата, описание, оплачено, не оплачено,
статус, действия.

Статусы: `Charged` оплачен, `open` ожидает, `Authorized` удержан, `void`
отменён.

Действия по строке: открыть ссылку, скачать PDF, чек, webhook, отмена hold.
Отмена hold из интерфейса есть — эндпоинта для неё в документации нет.

Поиск по номеру (полному или частичному), имени плательщика, телефону.
Фильтры по категории услуги и по статусу.

Кнопка «Создать инвойс» доступна мерчантам с ручными формами, для физического
или юридического лица.

## Отчёты

Две вкладки: «Оплаченные» и «Неоплаченные». Сводная таблица по сервисам за
выбранный период: количество и сумма. Клик по числу открывает детальный реестр
инвойсов в новой вкладке, оттуда выгрузка в Excel.

## Переводы

Консолидированные суммы, которые банк-корреспондент перечислил на расчётный
счёт организации за оплаченные инвойсы. SmartPay группирует оплаченные инвойсы
и формирует один перевод.

Колонки: идентификатор мемориального ордера, период группировки, получатель,
ИНН, банк, 20-значный расчётный счёт, сумма в TJS, количество инвойсов
(кликабельно), назначение платежа, дата мемориального ордера. Есть выгрузка CSV
за период.

Это раздел для сверки: сопоставлять свои оплаченные заказы с фактическими
поступлениями на счёт.

## Субагенты (splitting accounts)

Настройки → Субагенты. Автоматическое разделение платежа между несколькими
получателями. Нужен не всем — только если бизнес-модель делит поступления.

Комиссионная модель: фиксированная комиссия банка плюс комиссия агента плюс
комиссия платформы. Пример из документации: агент 97.5%, платформа 1.5%, итого
99% плюс 1% банка = 100%.

Карточка субагента: ИНН агента (с кнопкой «Проверить» и автозаполнением
наименования), банк, расчётный счёт, комиссия в процентах. Отдельно данные
платформы: ИНН платформы и владелец.

**Для Blast это ключевой раздел.** Схема «гость платит в заведении, заведение
получает деньги, Blast удерживает свой процент» — это ровно splitting accounts,
где заведение субагент, а Blast платформа.

## Dashboard

Четыре карточки за 30 дней: всего инвойсов, оплачено (сумма), оплаченных
инвойсов, неоплаченных инвойсов. Два графика: распределение по банкам и
ежедневные платежи. Период фиксированный, за произвольный — раздел «Отчёты».

## Подключение

Для доступа к sandbox заполняется форма с данными организации: название, адрес,
телефон, email, ИНН, банковские реквизиты, контактное лицо (ФИО, должность,
email, телефон), сайт, ссылка на логотип.
