# Референсы Бахтовара — разбор

Все разобраны покадрово (раскадровки через 0.25–0.5 с и 1/30 с вокруг переходов) и по звуку
(энергия по полосам + атаки, сверено с картинкой). Звук «на слух» не слушали — выводы
про эффекты надёжны там, где событие в звуке совпадает с событием на картинке.

## Как смотреть ссылку из Instagram

Обычная страница рилса просит вход — **пароль не вводить**. Работает
`https://www.instagram.com/reel/<id>/embed/` (параметр `?stkn=…` из его ссылки отбросить).
В панели браузера: видео-элемент на странице, `video.load()`, перемотка + `drawImage` на свой
canvas → лист кадров (холст «загрязнён», читать пиксели нельзя, но смотреть скриншотом можно).
Звук: `fetch(video.currentSrc, {mode:'cors'})` проходит (fbcdn отдаёт CORS) →
`OfflineAudioContext.decodeAudioData` → свой FFT в странице. Ничего не скачивается на диск.
В фоновых вкладках `requestAnimationFrame` стоит — заменить на `setTimeout`.

**opencompany.cloud** `DZNVG9Bowhq` (38 с). Много вставок по 0.4–0.6 с, склейка по

**sanya.creator** `DcQqiIwOZrI` (13 с) — урок по появлению текста. Helvetica Bold,

**niknaglapur** `DK-eHBCRINk` (50 с). Мелкий человек в большом пейзаже + полноэкранные

**opencompany.cloud** `DYMl48dKy9X` (54 с). Стол, вид сверху на зелёном коврике:

**opencompany.cloud** `DXYN_DEBRH4` (31 с, «I need your help»). Мелкое «I need» → под ним

**anderson.taii** `Da0d8suu6kJ` (19 с) — урок переходов, подписаны:
1. огромное красное «TRANSITIONS» **за** ним (голова и рука перекрывают) → зум с размытием;
2. засвет/световая вспышка (оранжевый пересвет 3–4 кадра);
3. «camera pivot»; 4. белая вспышка 2 кадра; затемнение ладонью в объектив (3 чёрных кадра);

Эффектов в звуке почти нет — переходы держатся на картинке и музыке.
