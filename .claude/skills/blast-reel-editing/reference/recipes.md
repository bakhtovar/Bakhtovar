# Рецепты (проект `~/blast docs/video`)

Все пути — от корня проекта. Эталонная реализация — ролик «55 дней»: `src/days55/`,
скрипты `scripts/days55-*.py`, раздел в `README.md`. Начинай новый ролик с копии этой схемы.

## Инструменты

- **ffmpeg** — тот, что в Remotion: `node_modules/@remotion/compositor-darwin-arm64/ffmpeg`
  с `DYLD_LIBRARY_PATH` на эту папку. Минимальная сборка: нет `fps`, `tile`, `select`,
  `afftdn`, `highpass`. Есть `trim`, `scale`, `zscale`/`tonemap` (HLG → SDR для превью),
  `loudnorm`, `silencedetect`. Кадр — `-ss T -i файл -frames:v 1`; листы кадров — PIL.
- **Python** — numpy + PIL (scipy нет). **Swift** — есть (Vision для масок).
- **Шрифт** — Onest (`src/tchk/fonts.ts`, с `cyrillic-ext` для ӣ ҷ ҳ қ ғ ӯ). Цвет бренда #FF5A2B.
- `scripts/stills.mjs <comp> <dir> <scale> <кадры…>` — пачка кадров из одного бандла.

## Исходники

- Дубли iPhone: HEVC 2160×3840 ~60 fps, HLG, поворот 90°. Композиция 1080×1920 @ 30 fps.
- Черновик CapCut — JSON: сегменты (source/target в мкс), громкости, трек музыки (путь к
  файлу), loudness-нормализация по клипам. По нему восстанавливается монтаж из сырых дублей
  (без вшитых субтитров CapCut) → `capcut-edit.json`.
- Голос: если в экспорте CapCut уже музыка — рендерить голос из MOV по тому же списку
  клипов (`src/dev/VoiceTrack.tsx`) → `voice.wav`. Чистка `scripts/voice-clean.py`
  (спектральный гейт −12 дБ пол, срез < 80 Гц, выравнивание дублей по речи, мягкий 2:1)
  → `loudnorm=I=-16:TP=-1.5:LRA=7`.
- Опорный звук для таймингов — **только из рендера Remotion**: afconvert по AAC оставляет
  2112 сэмплов priming (+48 мс).

## Текст и тайминги

- whisper.cpp **1.6.2 с `--dtw medium`** (`scripts/install-whisper-dtw.mjs`,
  `scripts/transcribe-dtw.mjs`); 1.7+ требует cmake. Язык задавать явно: на таджикской речи
  с `ru` whisper уверенно пишет чепуху.
- Таймстемп-токены врут (первое слово в 0.00 при речи с 1.56); DTW отстаёт на 0.1–0.35 с в
  начале фраз и плывёт к концу. Поэтому `days55-captions.py`: паузы ≥ 150 мс по огибающей
  (−46 dBFS, 10 мс) — якоря; слово после паузы стартует в её конце, перед паузой — кончается
  в её начале, между якорями — по относительному DTW. Крупные слова — на атаку взрывного
  (провал → подъём ≥ 7 дБ).
- Текст на экране — из эталона `data/<ролик>/script.txt` (строка = блок, `[акцент]`,
  `~` вырезано), whisper даёт только часы. Сомнительные слова — спроси у него.
- Склейки — только в тишине: `days55-edit.py` берёт границы фраз по огибающей,
  паузы > 0.42 с сжимает до 0.24 с. Молчаливое начало не считать паузой.

## Картинка

- **Укрупнение** на стыке одного дубля: scale 1 ↔ 1.12, origin на лице (у этих дублей
  `50% 42%`: много стены сверху, подбородок на y ≈ 1000).
- **Телефон с приложением** (`Inserts.tsx`): экран 756×1640 + бортик 16, тень, тёплое
  свечение сзади; камера = `{zoom, focus (px записи), y}` на каждый кадр вставки, переход
  камеры 12 кадров; акции — `hold` (стоп-кадр, чтобы прочитать); под субтитрами тёмный
  градиент 52 %→68 % (белый текст на светлой карте иначе бледнеет).
- **3D-рендер 1920×1080** → кроп 9:16 (608×1080) крупного плана × 1.78. Плашку
  «Made in Raylight» (x 1624–1890, y 996–1050) держать вне кропа.
- **Зум с размытием**: выход 3 кадра (scale до 1.18, blur до 16), вход 5 кадров обратно.
- **Whip pan** (`Whip.tsx`): SVG `feGaussianBlur stdDeviation="X 0" edgeMode="duplicate"`,
  `colorInterpolationFilters="sRGB"`; выход 4 кадра (сдвиг до −170 px, scale до 1.34,
  смаз до 70 px, ускорение), вход 5 кадров зеркально; склейка в середине смаза.
- **Текст за человеком**:
  1. маска — `swift scripts/person-matte.swift <MOV> <dir> <кадры дубля>` (Vision
     `.accurate`, кадр ровно в frame/30 с поворотом) → альфа-PNG 540×960;
  2. `scripts/smooth-mattes.py` — сглаживание по 5 кадрам (1·2·3·2·1)/9 и ужатие на 2 px:
     иначе край волос «дышит» и стена каймой ложится на цвет;
  3. `scripts/days55-cutouts.py` — рендер композиции `PlateOnly` (тот же план без текста →
     те же цвета) на этих кадрах, вырезка по маске → `public/<ролик>/cutout/<кадр>.webp`;
  4. в ролике: текст, поверх — `<Img>` вырезки. **Не CSS mask-image** по видео: Chrome
     иногда рисует кадр до применения маски — текст выскакивает поверх головы.
  Позиция: цифра 760 px сверху ~190, слово 340 px сверху ~410 — голова перекрывает низ.
- **Финальная карточка**: обложка проявляется за ~12 кадров со 106 %, последний кадр под
  ней размывается и темнеет, потом медленный наезд 1.5 %. Хуки — до любого раннего `return`.

## Звук

- Голос −16…−17 LUFS. Музыка — `BASE_DB` на файле трека с подъёмом в паузах и на карточке,
  в ноль к последнему кадру. История «55 дней» (трек −17.5 / −15.1 LUFS до/после дропа):
  −10 → −7 («слышнее») → −9 («потише») → −12 («ещё −3 дБ»). Итог ролика −16.4 LUFS, пик −2.2.
- Дроп песни можно посадить на ключевую склейку сдвигом начала трека (по огибающей файла
  найти вступление барабанов).
- Эффекты синтезировать (`scripts/days55-sfx.py`): whoosh 0.4 с (шум 600→3500 Гц,
  нарастание, конец на склейке, −15…−17 дБ), boom 0.7 с (синус 90→42 Гц + щелчок 4 мс,
  −12 дБ) под крупное слово, riser к карточке (−20 дБ).

## Проверки готового файла (каждый раз)

- Все кадры: средняя яркость < 10 → пустой кадр.
- Текст за ним: для каждого кадра — оранжевые пиксели внутри маски в зоне головы/плеч
  (выше субтитров) должны быть ≈ 0. Так нашли сбой на кадре 360.
- Переходы: кадры вокруг склейки листом (±5).
- `loudnorm=print_format=summary` по самому mp4 (`-vn`), стерео, а не моно-сведение.
- Последние 10 мс звука ≈ −40 дБ и тише.

## Ловушки

- Студия тормозит на нескольких 4K HEVC — синхрон только по рендеру.
- Удалять `node_modules/.cache` при запущенной студии — падает.
- Tailwind preflight (`max-width:100%`) ломал OffthreadVideo — в проекте его нет, у видео
  `maxWidth: 'none'`.
- `Freeze` за пределами длины композиции ничего не рисует.
- Регистр файлов: macOS не различает `captions.ts` и `Captions.tsx`.
- Импорт типа и компонента с одним именем — переименуй тип при импорте.
- Правки нескольких файлов при открытой студии ловят промежуточное состояние → белый экран;
  после правок перезагрузить вкладку студии.
