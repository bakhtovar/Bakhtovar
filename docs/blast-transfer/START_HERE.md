## Правила работы (обязательные)

1. **Ветки.** Любая правка — в новой ветке от `main`. `gh` не установлен, поэтому:
   коммит в ветку → `git merge --no-ff` в `main` с сообщением «Слияние: …» →
   `git push origin main <ветка>`. Сообщения коммитов — по-русски.
2. **Боевая база.** Изменения схемы, функций и pg_cron классификатор авто-режима
   обычно не даёт делать самому. Порядок такой:
   - функцию правишь только от живого определения (`pg_get_functiondef`), иначе
     рядом встанет второй оверлоад;
   - миграция — файлом `supabase/migrations/<номер>_<имя>.sql` в репозитории приложения;
   - проверка — `supabase db query --linked -f файл.sql` с `begin … rollback`;
   - применение — Бахтовар запускает `python3 tool/apply_migrations.py <номер>`
     (одна транзакция + строка в истории). «duplicate key schema_migrations_pkey» после
     сбоя связи обычно значит «применилось» — проверь историю.
   - Чтение базы (`supabase db query --linked`) работает и без него.
3. **Деплой сайта и панелей** тоже запускает Бахтовар:
   `cd ~/blast\ docs && npx wrangler deploy`. Панели сначала собрать (`npm run build`)
   и скопировать `dist/` в `site/admin` или `site/teamcave`.
   Лист ожидания — `npx vite build --base=/waiting/`. Проверять выкладку на
   `https://www.blastpay.tj/...` (апекс отвечает 301).
4. **Секреты** не печатать, не коммитить, не класть в архивы. Ключи живут в `.env*`
   файлах (вне git) и в секретах Supabase Edge Functions.
5. **Netlify не используется.** Старые адреса `*.netlify.app` не упоминать.
6. Приложение запускать только через `make run DEVICE=<udid>` (читает `.env.local`),
   релизы — `make aab` и `make ipa`. Без `--dart-define` будет белый экран.

## Продуктовые решения, которые нельзя «чинить»

- **Геолокация не блокирует активацию** — так задумано. Присутствие подтверждает
  QR-наклейка; расстояние только записывается.
- **Дневного лимита на гостя нет** (с 29.09). Остаются лимиты самой акции и ёмкость
  заведения в день.
- **Акции без проверки Blast** (с 01.10). Заведение само публикует акцию и правит
  условия живой. Не возвращать модерацию без его слова.
- **Ранний доступ выключен** с 14.09 (ради App Review). Не включать без его слова.
  Доступ выдан всем зарегистрированным; основатели — он, Некруз, cc4771168@gmail.com.
- Версии: одна на iOS и Android, сейчас **1.1.2 (3)**. Поднял версию — номер сборки с 1.
  Android считает versionCode сам: `major*1e6 + minor*1e4 + patch*100 + build`.
