С 23.09.2026 весь веб Blast набран **Onest** (400/500/600/700) с моно
**IBM Plex Mono** (400/500). Manrope, Unbounded и JetBrains Mono убраны
отовсюду — гарнитуры названы ровно в одном месте каждого проекта, двумя
переменными `--font-sans` и `--font-mono`, всё остальное ходит через них.

Файлы `.woff2` раздаёт сам домен, Google Fonts нигде не подключается:
из Душанбе он отвечает не всегда. Набор собирает `~/blast docs/tools/fonts.py
<путь к проекту>` — качает подмножества latin/latin-ext/cyrillic/cyrillic-ext
и пишет рядом `fonts.css`. У проектов на Vite кладёт в `public/fonts/`,
у голого сайта — в `fonts/` в корне. Подключение одинаковое: `preload`
обычного кириллического начертания плюс `<link>` на `fonts.css`.

**Ловушки.**
- Таджикские ӣ ҷ ҳ қ ғ ӯ живут в подмножестве `cyrillic-ext` — выкидывать
  его нельзя. Обе гарнитуры их покрывают, проверено по cmap.
- У Onest нет 800-го начертания: где в вёрстке стояло `font-weight: 800`,
  теперь 700, иначе браузер рисует наклонную подделку.
- Лендинг `site/index.html` возил шрифты внутри себя — 98 правил
  `@font-face` с base64 в gzip-ассетах бандла. Вырезает их шаг 16 в
  `patch-landing.py`; обычный grep по файлу их не видит.
- `tools/dashboard.py` генерирует разметку дашборда на лендинге — шрифты
  там тоже надо держать переменными, иначе повторный прогон
  `patch-landing.py` впишет старые обратно.

**Why:** гарнитура задаётся в четырёх репозиториях сразу, и половина мест
(бандл лендинга, генератор дашборда) не находится поиском по тексту.

**How to apply:** менять шрифт — только через переменные и `tools/fonts.py`,
потом пересобрать панели и прогнать `patch-landing.py`. Где что лежит —
[[blast-admin-panels]], выкатка — [[blast-site-infra]].
