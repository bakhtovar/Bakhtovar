29.09.2026 пользователь попросил удалить старые ветки, а классификатор авто-режима
отказал с [Git Destructive]. Обходить нельзя: ни по частям, ни другим инструментом.

**Why:** отказ относится к результату, а не к команде; повтор в другой форме —
это обход.

**How to apply:** на просьбу удалить ветки сначала собрать список и проверить
слитость (`merge-base --is-ancestor origin/<b> origin/main`), а затем отдать
пользователю готовые команды `git -C <repo> push origin --delete …` и
`git -C <repo> branch -d …` по одной в блоке ```bash```, указав SHA неслитых
для восстановления. Ветки параллельной сессии за сегодня не трогать.
