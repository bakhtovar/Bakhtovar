`BlastColors` — глобальная статика (`BlastColors.use(palette)` подменяет
палитру целиком, чтобы не переписывать 669 обращений на чтение из
`context`). Побочный эффект: **виджет без полей схлопывается в константу, и
при смене темы Flutter его не перестраивает** — `Element.updateChild`
видит тот же экземпляр и пропускает rebuild. Цвет остаётся из палитры, с
которой приложение запустилось.

Так капсула таб-бара (`const _Pill()`) в светлой теме оставалась тёмной:
#1C1C22 на белом.

**How to apply:** если приватный виджет читает `BlastColors` и у него нет
полей, добавь параметр, который меняется вместе с темой
(`_Pill({required this.dark})`, зовётся как
`_Pill(dark: BlastColors.current.isDark)`). Либо задавай цвет
прозрачностью поверх подложки — она работает в обеих темах.

Проверять смену темы только на живом переключении в Настройках: `xcrun
simctl ui <udid> appearance dark` приложение игнорирует, тема хранится
своя (Профиль → Настройки → Тема оформления).
