Документация SmartPay на `https://smartpay.tj/dev/*` — React-SPA. Печать в PDF
и WebFetch дают только шапку: параметры инвойса, поля webhook и схема подписи
в них обрезаны.

Полный текст лежит в бандле `https://smartpay.tj/static/js/main.<hash>.js`
(хэш берётся из `src=` на любой странице `/dev/`). Строки там в `\uXXXX`, после
декодирования ищутся по якорям вроде «Параметры запроса», «Коды result»,
«Формат уведомления». В файле есть суррогатные пары — при декодировании нужен
`.encode("utf-16","surrogatepass")`.

**Почему:** без этого легко написать интеграцию по обрезанной версии и не
узнать, например, что поллинга статуса нет.

**Как применять:** прежде чем верить PDF документации SmartPay, тянуть бандл.
Собранные тексты уже лежат в `[[smartpay-skill-location]]`.
