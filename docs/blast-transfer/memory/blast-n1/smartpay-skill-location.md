Скилл `smartpay` в репозитории Blast: `.claude/skills/smartpay/`. Внутри
`references/` (api, webhooks, deeplinks, dashboard, blast-integration) и
`graph/` — отдельный граф знаний на 171 узел плюс исходные тексты PDF.

Граф SmartPay намеренно отдельный от `graphify-out/` в корне: там 4572 узла
кода, документация внешнего шлюза в них тонет.

Тестовый API-ключ SmartPay лежит в `.env.smartpay` в корне репозитория. Файл
под `.gitignore` (правило `.env.*`). Ключ серверный: он не должен попадать
в `--dart-define`, его место — secrets Supabase Edge Function. Живой ли ключ,
не проверено: отправку ключа на внешний хост заблокировал классификатор.

Ветка работы — `feature/smartpay-payments`, отведена от `main` 8 сентября 2026
после слияния `feature/kaffeine-zaytun-real-data`, запушена.

Работа идёт по промту BLAST PAY вертикальными срезами: прототип и
спецификация лежат в `docs/blast-pay/`. Сделаны срез 0 (расчёт на сервере,
связь акции с позициями меню, снятие геопроверки) и срез 1 (экран статуса и
успеха). Остались срезы 2 (типы акций BOGO и GIFT), 3 (матрица ошибок) и
4 (после оплаты). Открытый блокер: вычитается ли стоимость подарка из суммы
платежа — это меняет экономику заведения, решает владелец.

Ключ проверен живым 8 сентября 2026: и `GET /banks`, и `POST /invoices`
проходят на sandbox. Проверять шлюз без гостя можно действием `probe` у
`smartpay-invoice` — нужен заголовок `x-diag-token`, значение лежит в
`.env.smartpay` рядом с ключом.

Диплинки банков приходят семью кастомными схемами (`eskhata`, `amonatbonk`,
`icbmobile`, `cbt`, `arvand`, `humoonline`, `ssb`) и шестью https-ссылками.
Кастомные объявлены в `Info.plist` и `AndroidManifest.xml`: без объявления
Android с API 30 говорит «приложения нет», даже когда банк установлен.

Вызвать Edge Function через `supabase functions invoke` нельзя — в
установленной CLI (v2.115) такой подкоманды нет. Только HTTP POST на
`https://lfudcjwkyctodeqaommv.supabase.co/functions/v1/<имя>` с anon-ключом
в `Authorization: Bearer`.

Вход в приложение агент пройти не может: только Google, Apple или ссылка на
почту. Но если сессия уже есть, весь остальной флоу проходится: код TEST →
SAPPORO → «Оплатить счёт» → позиция → банк → диплинк.

В симуляторе обязательно задать геопозицию, иначе активация ждёт GPS и
выдаёт «Сервер долго не отвечает» — ошибка выглядит серверной, а причина
клиентская:
`xcrun simctl location <udid> set 38.5739729,68.794625` — это SAPPORO.

**Почему:** ключ и граф лежат вне очевидных мест, а искать их по репозиторию
бесполезно — `.env.smartpay` не в git.

**Как применять:** при работе с оплатой сначала открывать скилл, а не искать
документацию заново. См. [[smartpay-docs-source]].
