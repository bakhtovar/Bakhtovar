# 10 · Подключённые скиллы

Все скиллы целиком скопированы в папку `skills/` этого архива — не только
описания, а весь код, шаблоны и справочники.

```
skills/
  личные/     ~/.claude/skills — доступны во всех проектах
  проектные/  .claude/skills в репозитории Blast Pay
```

| Скилл | Что делает | Размер |
|---|---|---|
| **graphify** | превращает любой ввод в граф знаний; для вопросов о коде — сначала запрос к графу, потом чтение файлов | 104 КБ |
| **impeccable** | большой фронтенд-скилл: дизайн, редизайн, критика, аудит, полировка, анимация, цвет. 148 файлов, из них 3 МБ скриптов | 3,4 МБ |

### graphify в этом проекте

У Blast Pay есть собственный граф знаний в `graphify-out/`. Это записано в
`AGENTS.md` проекта как правило:

- вопрос о коде → сначала `graphify query "<вопрос>"`;
- связи → `graphify path "<A>" "<B>"`;
- понятие → `graphify explain "<понятие>"`;
- широкая навигация → `graphify-out/wiki/index.md`;
- обзор архитектуры целиком → `graphify-out/GRAPH_REPORT.md`;
- после правок кода → `graphify update .` (только AST, без обращений к модели).

Грязные файлы в `graphify-out/` после хуков — норма, не повод пропускать граф.

Триггер — `/graphify`.

## Скилл `smartpay`

Самый важный из проектных. Собран потому, что официальная документация
SmartPay непригодна: **PDF на сайте обрезаны на второй странице**, полный
текст пришлось доставать из JS-бандла самого сайта.

Внутри — разобранный API, граф вызовов и тестовый ключ. Ключ лежит в
`.env.smartpay` **вне репозитория**; в этот архив он не попал (см.
`07-доступы.md`).

Используется при любой работе с приёмом платежей.

## Как они разложены в репозитории

Тринадцать из двадцати проектных скиллов в `.claude/skills/` — **символические
ссылки** на `.agents/skills/` в корне репозитория:

```
.claude/skills/brandkit  →  ../../.agents/skills/brandkit
```

Так они видны и Claude Code, и другим агентам, а лежат в одном месте.

Ссылками заведены: `brandkit`, `design-taste-frontend`,
`design-taste-frontend-v1`, `full-output-enforcement`, `gpt-taste`,
`high-end-visual-design`, `image-to-code`, `imagegen-frontend-mobile`,
`imagegen-frontend-web`, `industrial-brutalist-ui`, `minimalist-ui`,
`redesign-existing-projects`, `stitch-design-taste`.

Настоящими папками в `.claude/skills/` лежат: `animation-vocabulary`,
`emil-design-eng`, `find-animation-opportunities`, `graphify`,
`improve-animations`, `review-animations`, `smartpay`.

> В этот архив всё скопировано **с раскрытием ссылок** — в `skills/проектные/`
> лежат настоящие файлы, а не битые ссылки. Если будете возвращать их в новый
> репозиторий, решайте сами, раскладывать ссылками или папками.
