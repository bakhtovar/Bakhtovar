# Blast Pay — пакет знаний о проекте

Собрано 16 сентября 2026 года. Всё, что нужно знать, чтобы продолжить работу
над проектом, не перечитывая 38 тысяч строк кода.

## Как читать

Документы пронумерованы по порядку погружения. Если время есть только на два —
читайте `01-продукт.md` и `04-паттерны-и-конвенции.md`: первый объясняет, зачем
всё это, второй убережёт от половины ошибок.

## Что внутри папок

- `reference/` — копии живых документов проекта: дизайн-система, UX-спецификация,
  инструкции по пушам, заметки для ревью в магазинах. Это первоисточники, мои
  документы их пересказывают и связывают.

- `skills/` — копии подключённых скиллов, с инструкциями и данными.

## Чего здесь нет и почему

**Секретов.** Ни ключей Supabase, ни токена SmartPay, ни паролей. `07-доступы.md`
рассказывает, где они лежат и как называются переменные, но значений не приводит:
этот архив уедет туда, где его хранение никто не контролирует. Ключи переносите
отдельно и другим каналом.

**Рабочих заметок по проекту** (одиннадцать файлов памяти: почему принято то или
иное решение, где лежит то, чего нет в git, на чём уже обожглись). Они лежат
отдельно и в архив не вложены — в одной из них персональные адреса почты.
Существенное из них пересказано в документах 01–12; если нужны сами файлы,
попросите вложить их отдельно.

**Исходного кода.** Пакет описывает систему, а не заменяет репозиторий.
Репозиторий: `github.com/bakhtovar/Blast-Pay`, ветка `main`.

В двух скопированных документах (`reference/docs/app-review-notes.txt` и
`reference/docs/app-review-reply-2.1-signin.txt`) стоял настоящий пароль
демо-аккаунта для ревью Apple — при упаковке он вырезан и заменён пометкой.
Значение берётся в App Store Connect → Sign-In Information.
