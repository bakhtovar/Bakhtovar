# 07 · Доступы

> ## Здесь нет ни одного ключа
>
> В этом файле — **только имена переменных и адреса панелей**. Значений нет
> сознательно: архив уезжает туда, где его хранение никто не контролирует.
> Ключи переносите отдельно и другим каналом.

## Идентификаторы приложения

| | |
|---|---|
| iOS bundle id | `com.blastpay.app` |
| Android application id | `com.blastpay` |
| Apple Team ID | `LL8FZUAY98` |
| Версия сейчас | `1.0.3+10` |

> Bundle id **разные на платформах**. Это регулярно кусается: команды
> симулятора (`terminate`, `launch`) с чужим id не ругаются, а молча ничего
> не делают и рапортуют успехом.

## Что где лежит

| Что | Где хранится | Кто читает |
|---|---|---|
| Ключи для запуска | `.env.local` в корне проекта (в `.gitignore`) | `make run`, `make ipa`, `make aab` |
| Токен SmartPay | переменные окружения Edge Function в панели Supabase | только `smartpay-invoice` |
| `service_role` Supabase | панель Supabase | только Edge Functions |
| Подпись Android | `android/key.properties` + keystore (оба вне git) | `make aab` |
| Подпись iOS | связка ключей Xcode / Apple Developer | Xcode |
| Тестовый ключ SmartPay | `.env.smartpay` рядом со скиллом, вне репозитория | скилл `smartpay` |

## Переменные `.env.local`

Шаблон — `.env.example` в корне. Скопировать: `cp .env.example .env.local`.

```
SUPABASE_URL
SUPABASE_ANON_KEY          публичный по замыслу, безопасность держится на RLS
ENV                        local | staging | prod

GOOGLE_IOS_CLIENT_ID       нативный вход Google на iPhone
GOOGLE_WEB_CLIENT_ID       выдача и проверка ID token

GEOFENCE_RADIUS_M          радиус подтверждения присутствия, метры (150)

FIREBASE_API_KEY           ┐
FIREBASE_APP_ID            ├ Android: FCM + Crashlytics
FIREBASE_SENDER_ID         │
FIREBASE_PROJECT_ID        ┘

FIREBASE_IOS_API_KEY       ┐ iOS: только Crashlytics
FIREBASE_IOS_APP_ID        ┘ (пуши идут прямо через APNs)

CRASHLYTICS_IN_DEBUG       по умолчанию false
```

`service_role` в приложение не попадает ни при каких условиях.

Без Firebase сборка проходит — просто на Android не будет удалённых пушей
(останутся локальные напоминания), а падения никуда не уедут.

## Переменные Edge Functions

Панель Supabase → Edge Functions → Secrets.

```
SMARTPAY_BASE_URL          sandbox.smartpay.tj или ecomm.smartpay.tj
SMARTPAY_API_KEY           заголовок x-app-token
SMARTPAY_RETURN_URL
SMARTPAY_DIAG_TOKEN
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

|---|---|---|

bundle id. Поэтому и ключи в `.env.local` разные: общими остаются только
`FIREBASE_PROJECT_ID` и `FIREBASE_SENDER_ID`.

## Как поднять проект на чистой машине

```bash
git clone git@github.com:bakhtovar/Blast-Pay.git
cd Blast-Pay
cp .env.example .env.local     # заполнить значениями из безопасного канала
make setup                      # зависимости, токены, кодоген, формат
make run                        # запустить
```

**Не `flutter run`.** Без `--dart-define` приложение покажет белый экран без
единой ошибки в логах: `String.fromEnvironment` вернёт пустую строку, клиент
Supabase не поднимется. `make run` подставляет всё из `.env.local`.
