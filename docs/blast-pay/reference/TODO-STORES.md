# Что ждёт аккаунтов Apple и Google

Отложено сознательно: без платных аккаунтов разработчика это не проверить,
а писать «на глаз» и класть в репозиторий непроверенным — хуже, чем не писать.
Когда аккаунты появятся, идти по этому списку сверху вниз.

## Apple Developer — 99 $/год

- [ ] **APNs Auth Key (.p8)** — загрузить в Firebase Console, иначе push на iOS
      не уйдёт вообще. Ключ выдаётся один раз, скачать можно тоже один раз.
- [ ] **Push Notifications capability** в Xcode + `aps-environment` в
      entitlements. Сейчас в проекте только локальные уведомления
      (`lib/core/reminders.dart`), удалённых нет.
- [ ] **Associated Domains** — `applinks:blastpay.tj` для универсальных ссылок.
      Без него `/q/{code}` из камеры не откроет приложение (часть 7, §5).
      Плюс `apple-app-site-association` на blastpay.tj.
- [ ] **Sign in with Apple** — App Store требует его, если есть вход через
      Google. Сейчас Google-вход работает, Apple нет: заявку отклонят.
- [ ] **App Store Connect**: карточка, скриншоты, описание на ru/tg/en,
      политика конфиденциальности, App Privacy («Data Used to Track You» —
      ответ «нет», внешних SDK нет).
- [ ] **Подписки**, если решение остаётся платным: продукты в App Store
      Connect, StoreKit 2, серверная валидация чека. Внутриигровые платежи
      Apple обязана проводить через себя — SmartPay здесь не подойдёт.

## Google Play — 25 $ разово

- [ ] **google-services.json** для release-варианта: SHA-1 и SHA-256 ключа
      подписи. Сейчас в проекте только debug-ключ, и Google-вход в release
      молча не сработает.
- [ ] **FCM Server Key / service account** для Edge Function отправки пушей.
- [ ] **App Links** — `assetlinks.json` на blastpay.tj с отпечатком release-ключа.
- [ ] **Play Console**: карточка, скриншоты, Data Safety, целевая аудитория.
- [ ] **Play Billing**, если подписка платная. То же ограничение, что у Apple.

## Что от этого зависит в коде

| Готово | Ждёт аккаунта |
|---|---|
| Локальные напоминания | Удалённые push (FCM/APNs) |
| Deep links внутри приложения | Универсальные ссылки из камеры и почты |
| Google-вход в debug | Google-вход в release, вход через Apple |
| Витрина тарифов | Реальная оплата подписки |

## Порядок

1. Google Play — дешевле и быстрее, разблокирует FCM и release-вход.
2. Apple — дольше по проверке, начинать заявку раньше остального.
3. Платежи — последними: до них надо закрыть юридический вопрос из ТЗ
   части 6, §2 (кто получатель денег и нужен ли статус посредника).

## Что уже готово и ждёт одного ключа

Отправка уведомлений собрана целиком, кроме доступа в FCM:

- очередь `notification_outbox`, тихие часы, суточный лимит и «один раз на
  визит» проверяются в базе — их видно запросом уже сейчас;
- cron `dispatch-push` раз в минуту дёргает Edge Function `send-push`;
- функция отвечает `skipped: FIREBASE credentials are not configured` и
  помечает записи, ничего не теряя.

Чтобы включить, нужно ровно одно:

```bash
supabase secrets set FIREBASE_SERVICE_ACCOUNT="$(cat service-account.json)" \
                     FIREBASE_PROJECT_ID=blast-XXXX
```

После этого записи из очереди пойдут в FCM без изменений в коде.
Регистрация токена на устройстве (`register_push_token`) ждёт
`firebase_messaging` — пакет добавится вместе с `google-services.json` и
`GoogleService-Info.plist`, которых без аккаунтов не существует.

## Что осталось после частей 6–8

Бэкенд закрыт целиком, включая роли заведения, подтверждение через
персонал, отчёты и начисления. Не сделано намеренно:

- **Веб-кабинет мерчанта** (Next.js либо Flutter Web). Все функции, на
  которых он держится, уже есть и проверены: `my_venues`, `venue_visits`,
  `venue_overview`, `venue_stats_range`, `venue_today`, RLS на офферах.
- **Админка**: очередь модерации, разбор споров (`admin_resolve_dispute`),
  флаги антифрода, правка `app_config`, слово дня. Журнал `admin_actions`
  пишется с первого действия.
- **Генерация печатных PDF с наклейками** — коды уже есть в
  `venue_qr_codes`, не хватает вёрстки листа.

По ТЗ кабинет и делается после мобильного приложения; здесь он не начат,
а не начат наполовину.
